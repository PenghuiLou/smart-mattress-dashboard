# 老人智能床垫机构管理驾驶舱

面向养老机构的老人智能床垫监测驾驶舱数据大屏（Demo）。

深色专业、温和可信赖的 1920×1080 网页数据大屏，用于展示养老机构床位状态、智能床垫设备运行、心率/呼吸趋势、风险告警和护理处置效率。当前仅使用 Mock 数据，不连接真实硬件和后端接口。

> ⚠️ 本页面所有健康数据均为**演示数据，仅供照护参考，不构成医疗诊断**。

## 功能模块

- **顶部**：机构信息、当前时间、数据更新时间、自动刷新状态、全屏/刷新按钮
- **核心指标**：监测床位、设备在线率、当前在床、离床未归、待处理告警、今日告警、平均响应
- **左侧**：风险概览、今日告警类型分布、近 24 小时告警趋势（可按类型切换）
- **中央**：楼层/房间/床位状态总览（支持楼栋/楼层筛选，点击床位查看详情抽屉）
- **右侧**：实时告警中心、告警处置进度、告警详情弹窗（确认处理/转派/关闭）
- **底部**：设备在线率趋势、健康监测风险分布、护理响应效率、近 7 日告警趋势

## 技术栈

- React 19 + Vite 4 + Tailwind CSS 3
- Recharts（图表）
- lucide-react（图标）
- 统一 Mock 数据源（`src/data/mockData.js`）

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`。若部署到 GitHub Pages 项目子路径，`vite.config.js` 中的 `base` 已配置为 `/smart-mattress-dashboard/`。

## 目录结构

```text
src/
├── components/cockpit/   # 驾驶舱各面板组件
├── data/mockData.js      # 统一 Mock 数据源
├── hooks/useDashboardData.js  # 数据与刷新钩子
├── pages/Cockpit.jsx     # 驾驶舱主页面
├── types/index.js        # JSDoc 类型约定
├── dashboard.css         # 驾驶舱深色主题样式
├── index.css             # Tailwind 入口
└── main.jsx              # 应用入口
```

## 交互说明

- 页面默认每 30 秒自动刷新 Mock 数据时间戳与趋势，也可手动刷新（轻量 loading，不整页白屏）
- 告警状态流转：待确认 → 处理中 → 已关闭；待确认 → 已转派 → 处理中 → 已关闭
- 设备离线或信号不足时，床位详情中的心率/呼吸显示「暂无有效数据」
- 文案统一使用「监测数据 / 趋势 / 风险提示 / 待人工确认」，不使用医疗诊断表述
